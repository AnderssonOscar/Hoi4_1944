# test runs exactly the same code as the decisions and events.

# KONR, option A: two more divisions of the author's Russian Liberation Army
# template, at low experience and half equipment, like the author's own
# divisions. The equipment they arrive with is paid from our stockpile: a full
# division needs 1,610 rifles, 30 support equipment and 12 guns (16 infantry
# battalions, an engineer and an artillery company), so half is 805, 15 and 6.
# The 4th division is raised at once, the 5th after 60 days (event
# ger_measures.2), each paid when it is raised.
#
# The payment is taken type by type (oldest first): removing by the general
# type (infantry_equipment) would take the amount from every type in stock
# (measured in the game, CHANGELOG section 17).
# Raised in Wuerttemberg (52) or Baden (50), where the KONR divisions were
# formed (Muensingen, Heuberg), else in any other German core state we hold.
GER_measures_konr_divisions = {
	GER_measures_konr_pay = yes
	GER_measures_konr_4th_division = yes
	hidden_effect = { country_event = { id = ger_measures.2 days = 60 } }
}
