How to read it: each slot of the list (pointer at r14) holds an entry whose +0x10 is the time left. 737533 counts it
down; when it reaches 0, the entry's decision (rbx) is taken out of a second list (737550-73758D), then 7375B5 calls
0x7281C0, the function that runs the decision's "remove" effect (it references the string 'remove'), then 7375C5
works out a new timer value, and 7375D7/7375DA write it back into the slot: rcx = [r14]; [rcx+0x10] = eax.

out of the list, the game filled its slot with the last entry and emptied the last slot, and then wrote the new timer
into the old, empty slot. The game's own removal code does exactly this: 7374F1-7374FA in the same function moves the
last entry into the freed slot and writes 0 into the last slot.)
